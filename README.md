# Streamlit và Web UI thông thường

Bài trình chiếu HTML tương tác bằng tiếng Việt giới thiệu sự khác biệt giữa Streamlit và giao diện web thông thường.

Xem trực tuyến: https://ducduong12123.github.io/streamlit-vs-web-ui/

Để dùng trên máy, tải tệp `index.html` và mở bằng trình duyệt. Có thể chuyển trang bằng các nút điều hướng hoặc phím mũi tên.

Phần ví dụ là mô phỏng bằng JavaScript và không chạy ứng dụng Streamlit thực tế.
